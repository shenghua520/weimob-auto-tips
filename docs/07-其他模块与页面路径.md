# 07 · 其他模块与页面路径

> 这一章是"查地图"用的：已探明的模块入口 + 页面路径，接口只写实测过的。

## 1. 通用 URL 规律

```
https://master.weimob.com/bos/products/<productCode>/<BOS_ID>/<KEY>/<模块内路由>
```

`<KEY>` 每换一个 productCode 就换一次，**不能跨产品线拼 URL**。要直达某页面，直接从
`queryCacheableMenus` 的 `url` 字段取（见 02 文档），别手拼。

## 2. 财务中心（店铺 > 财务中心，productCode = `mpfinance` / `ecOrder`）

| 功能 | 路由 |
|---|---|
| 营收概况 / 交易明细 | `mpfinance/.../finance/online-trade` |
| 交易对账（线上交易/退款/分账/微信对账） | `finance/online-trade` 系列 |
| 应付管理（应付账单/提现/付款记录） | `finance/withdraw-list` |
| 业务对账（小红书/快手分账、组织收入与结算明细） | `finance` 下 |
| 分账设置 / 物流账户 | `mpfinance` · `mplogistics` |
| 支付管理（账号/收款配置/线下收款） | `mpfinance/.../payment/account` |
| **发票管理**（开票管理/电票订单/电票配置） | `ecOrder/.../financial/invoicemanage` |
| 经营目标 / 业绩管理 | `mpfinance` 下 |

> 注意 `发票管理` 挂在 `ecOrder` 产品线下，不在 `mpfinance`；`物流账户` 在 `mplogistics`。
> 跨产品线是微盟的常态，**看 URL 不看菜单分组**。

## 3. 运费模板（重灾区：菜单里搜"运费"是 0 条）

菜单全文检索 `运费` → **0 命中**。它藏在页内页签里：

```
商城 > 商城设置 > 配送设置 > 商家配送
  └─ 页内页签：配送设置 ｜ 运费模板管理 ｜ 物流公司管理
```

直达：`ecSetting/<bos>/<key>/setting/shopset/deliverset`

### 实测该商户的模板（2026-10-26）

| 模板名 | 关联商品 | 规则 |
|---|---|---|
| **不包邮（默认模板）** | 180 个 | 24 省可配送，首件 1 件 10 元，续件每 1 件 +2 元 |
| 邮路包邮 | 0 | — |
| 全国包邮 | 0 | — |

模板支持：新建 / 设为默认 / 编辑 / 复制 / 删除。

### 单个商品挂模板

```
商城 > 在售商品 > 商品列表 > 行内「编辑」
  → 编辑页页签「支付信息」→ 区块「配送&服务」
  → 勾「商家配送」+ 选「运费模板*」
```

商品编辑页地址形态：`ecGoodsmanage/<bos>/<key>/goods/editNoMenu?id=<goodsId>&type=sale&saleChannelType=3`

### 批量改运费：不支持

商品列表「批量修改」= **导入修改**，左侧只有：
`商品信息 / 规格信息 / 修改图片 / 上下架状态 / 修改价格 / 虚拟库存 / 成本价 / 会员价 / 预售数量 / 次卡信息`
—— **没有运费模板**。只能逐商品编辑，或改模板本身（影响所有关联商品）。

## 4. CRM（productCode = `onecrm`）

菜单里**找不到"积分""储值"字样**，它们在资产管理下：

| 功能 | 路径 | 说明 |
|---|---|---|
| 积分规则 / 积分流水 | `CRM > 资产管理 > 积分管理` | `onecrm/.../integral/integralRule` |
| 储值规则 / 储值流水 | `CRM > 资产管理 > 储值管理` | `onecrm/.../balance/balanceRule` |
| 优惠券 | `CRM > 券码中心 > 优惠券` | 店铺券 / 微信商家券 / 支付宝商家券 / 抖音团购券… |
| 会员等级 | `CRM > 会员体系 > 等级会员` | `onecrm/.../member/member-setting` |
| 客户列表 | `CRM > 客户360 > 客户管理` | `onecrm/.../customer/customer-list` |

> 券码中心用的是 `onecrm01` 产品线（`couponcode/couponcode-set`），又是跨产品线。

## 8. 电商商品设置（`ecGoodsmanage/.../setting/goodsSetting`）

这里没有运费、没有库存，只有：

- 零售价格设置：销售价 / 市场价 / 划线价（按系统默认 or 统一显示市场价）、价格样式
- 批发价格设置（需购买插件）
- 商品搜索：内部搜索 / 外部搜索、名称分词、规格条码截取位数
- 商品图片比例：正方形 750×750 / 长方形 750×1000 / 超长 750×1100 / 宽图 750×424
- 到货提醒、商品评论（自动评论时间/内容/默认状态）
