# 官方 02 · iPaaS 私域网关（admin-api / API Token）

> 微盟提供的**第二条通道**：私有网关 API，用静态 token 鉴权，只读为主。
> 它比 WOS 简单（不用 OAuth），但**稳定性没有承诺** —— 官方口径是"私有网关，随时可变"。
> 介于"官方开放平台"和"后台内部接口"之间。

## 1. 是什么

微盟 iPaaS 网关，封装了后台常用查询，供第三方工具/脚本调用。

| 项 | 说明 |
|---|---|
| 鉴权 | 静态 **API Token**（后台「账户信息 → API Token」获取） |
| 环境变量 | `WEIMOB_ADMIN_TOKEN` |
| 必填参数 | `WEIMOB_ADMIN_TOKEN` / `bosId` / `vid` / `vidType` |
| 能力范围 | **18 个只读查询命令** |
| 写操作 | ❌ 无 |
| 稳定性 | ⚠️ 私有网关，**随时可变**，无版本承诺 |

## 2. 18 个查询能力

| 类别 | 能查什么 |
|---|---|
| 商品 | 商品列表 |
| 订单 | 订单列表、订单详情 |
| 售后 | 售后列表、售后详情 |
| CRM | 会员统计、客户个人资料、客户列表搜索 |
| 店铺 | 数据概览、待办事项 |
| 导购 | 导购业绩、导购线索 |
| 资产 | 积分方案与流水、储值方案与流水 |
| 基础 | 商户列表、门店列表、商户/门店切换 |

## 3. 调用方式

官方给了两套等价实现（Python / curl+jq）：

```bash
# Python 模式
python3 scripts/weimob_api.py <command> [args]

# curl + jq 模式
bash scripts/<command>.sh [args]

# 版本检查（每天一次）
bash scripts/check_update.sh
python3 scripts/weimob_admin.py update
```

请求形态（curl 模式的本质）：

```
POST https://<iPaaS 网关>/<资源路径>
Header: token: $WEIMOB_ADMIN_TOKEN
Header: Content-Type: application/json
Body:   { "bosId": "<BOS_ID>", "vid": "<VID>", "vidType": 2, ... }
```

> 网关域名与具体路径由工具包内部维护，**不要硬编码到业务代码里** —— 升级时会变。
> 需要精确路径时看 `scripts/` 里的实现，而不是猜。

## 4. 和另外两条通道的关系

```
官方 WOS（OAuth）        ← 生产首选，26 域，读写都有
   ↑
iPaaS 私域网关（Token）  ← 只读够用、不想配 OAuth 时的轻量选择
   ↑
后台内部接口（Cookie）   ← 后台页面能做但前两者没覆盖的，最后手段
```

三条通道覆盖有重叠（都能查订单/商品/客户），**优先用上面两条**。

## 5. 选择建议

| 场景 | 选哪条 |
|---|---|
| 每天跑的经营报表、定时任务 | **WOS**（有版本，不会半夜因为前端发版挂掉） |
| 一次性查几个单、几个商品 | iPaaS 私域网关（省事，只读无风险） |
| 需要改价、改库存、发券 | **WOS**（私域网关没有写能力） |
| 后台页面有、WOS 没有（如清空商品分组、清素材） | 后台内部接口（见 [自查-01](自查-01-后台内部接口.md)） |
| 需要积分/储值流水的特定字段格式 | iPaaS 私域网关（这块比 WOS 直接） |

## 6. 注意

- Token 是**静态凭据**，泄露即等于后台只读权限外泄，**不要提交到 Git**
- 没有写能力，所以不存在误操作风险 —— 这也是它适合"随手查一下"的原因
- 工具包会每天检查更新，**升级前先看 CHANGELOG**，路径和参数有可能变
