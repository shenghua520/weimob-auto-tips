# 19 · 两套排序独立重排（商品列表 + 积分商城）

> 实测 2026-11-16 ｜ 512 可见商品 + 512 隐藏复制体 + 400 积分商品全量重排，零误改。
> 前置：[14 · 兑换商城排序重排](14-兑换商城排序重排与安全写入.md)（积分 sort 接口与值域复用纪律）、[18](18-商品复制改组与积分替换实战.md)。

---

## 一、用户口径：号段 = 展示顺序，两套排序都要用

| 一级分组 | 起始序号 | 结束序号 | 号位数 |
|---|---|---|---|
| 学习文具 | 1 | 2000 | 2000 |
| 体育用品 | 2001 | 4000 | 2000 |
| 少儿护理 | 4001 | 6000 | 2000 |
| 少儿穿戴 | 6001 | 8000 | 2000 |
| 少儿食品 | 8001 | 10000 | 2000 |
| 家庭日用 | 10001 | 12000 | 2000 |
| 读物潮玩 | 12001 | 14000 | 2000 |
| 米面油品 | 14001 | 16000 | 2000 |
| 家用电器 | 16001 | 18000 | 2000 |

**关键换算**：两套 sort 都是「数字越大越靠前」，所以号段要**镜像**——`sort = 18001 − 展示位`。学习文具展示位 1~2000 → sort 18000~16001（排最前拿 18000），家用电器 → sort 2000~1。

**两套字段独立**（docs/14 已实测）：

| 系统 | 接口 | body 关键字段 | 排序对象 |
|---|---|---|---|
| 商品列表 | `mall/goods/batchUpdateGoodsSort` | `goodsIdList[]` + `sortNum` | 不带（兑换）的 512 可见商品；**复制体跟随源商品同 sort**（隐藏不独立排名） |
| 积分商城 | `mall/point/goods/updatePointGoodsSort` | `goodsId` + `pointClassifyId` + `sort` | 400 积分商品（都在（兑换）组）；段内二级分组聚集 + 总价升序 |

## 二、本次规则（与 14 章不同，别照抄）

```
商品列表：一级分组号段 → 段内 minSalePrice 升序
积分商城：一级分组号段 → 二级分组聚集（商品分组树 sort 降序）→ 总价升序
总价 = 每 SKU (point/10 + pointPrice)，多 SKU 取 min（10 积分 = 1 元）
```

> `minPointPrice` 不是「所有 SKU 现金最小值」（14 章坑 #10），必须逐 SKU 算总和。

---

## 三、商品列表 sort 写接口怎么找（14 章没记的部分）

1. **编辑页没有排序字段**——别在 `goods/editNoMenu` 里找，白费。
2. 真入口在**商品列表的「排序」列**：单元格 `editable-cell` + 数值 + `.wospc-Edit` 铅笔图标，点铅笔出气泡编辑框。
3. 气泡原文：**「数字越大排序越靠前，数字重复则最新创建的靠前」**——方向依据。
4. 拦截用 `page.route()` 层（09#34），抓到：
   ```jsonc
   // POST /api3/mall/goods/batchUpdateGoodsSort
   { "basicInfo": {...}, "solutionType": 2, "goodsIdList": [161785873100397], "sortNum": 55555, ... }
   ```
5. **表格定位坑**：页面有广告假表格也含「排序」表头，必须按「含商品名称+排序列头 且 行内含 ¥」锁定真表格；首行是虚拟滚动占位行，要跳过。

## 四、数据准备与执行

- 计划表（`60`）：商品 512 源（全部有复制体可配对）+ 积分 400，全部匹配号段、零 leftover；每 SKU 总价从 `queryPointGoodsDetailForManagement` 取。
- 小样（`--test`）：各 12 条 → 回读目标 sort 零不符 → **自动回滚**。
- 批量（`--apply`）：写前回滚文件先落盘（`61-sort-rollback.json`，含源/复制体各自旧 sort），商品 512 源 + 512 复制体、积分 400，回读零不符。
- 独立复核（`62`，重新登录、不复用写入运行时）：目标 sort 命中 512+512+400 全对；价格升序逆序 0；sort 值域唯一；20 个抽样源无一出现在积分侧（两套字段独立）。

> 复核曾报 5 处逆序，独立回读变 0——写入后列表视图瞬时未收敛，**以重新登录的独立回读为准**（与 14 章「VOLATILE 字段只报告」同精神）。

---

## 五、一句话记住

> **号段=展示序，sort 越大越靠前 → 镜像换算；商品/积分两套 sort 各排各的，复制体跟随源商品 sort。**
