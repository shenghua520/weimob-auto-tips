## 一、两条前置事实

### 1. 表格 API 的行列参数是 **0 基下标**

```python
td.call_tool('sheet-mcp', 'get_cell_data', {
    'file_id': FILE_ID, 'sheet_id': '000004',
    'start_row': 0, 'end_row': 260,   # 0 = 表头行
    'start_col': 0, 'end_col': 19,    # 0 = A 列（序号）
    'return_csv': True})
```

- `start_row=1` 会**跳过表头**，`start_col=1` 会**跳过 A 列**。
- Excel 行号 = 下标 + 1；列字母 = `chr(65 + 下标)`；`set_range_value` 的 `row`/`col` 同样 0 基。
- 曾用 `start_col=1` 读表，漏掉序号列还误判"这表没有序号列"，列映射整体错位。

### 2. 下拉是**动态引用**字段说明的清单列

字段说明 sheet `00000a`「三、下拉选项清单」：表头在 Excel 行 42，**选项从行 43 起连续填**（每列预留到 141 行 = 100 项容量）。9 张分表的 K 列下拉用 `OFFSET+COUNTA` 引用这些列，**改字段说明即同步 9 张分表**。

> 写不在清单里的值会被标"不符合下拉选项"，导入端按清单匹配会当空值处理 → **必须先补清单、再写值**。

## 二、微盟两套分组，取「可见组」名

微盟每个一级分组都有两套：`少儿穿戴`（`isShow=true`，可见）与 `少儿穿戴（兑换）`（`isShow=false`，积分商城用）。二者二级分组**同名 +「（兑换）」后缀**：

| 微盟（可见组） | 微盟（兑换组） | 表格 K 列应填 |
|---|---|---|
| 书包 `16482437100397` | 书包（兑换）`16532763100397` | 书包 |
| 健康体态 `16551775100397`（isShow=false） | 健康体态（兑换）`16551950100397` | 健康体态 |

**K 列填去掉「（兑换）」后缀的可见组名**（与表格下拉清单同源）。

> 注意：微盟**新建的隐藏分组**（如 健康体态）当初没进表格下拉清单 → 会出现"微盟有分组、表格清单没有"的缺口，必须先补清单。

## 四、执行（scripts 111–113）

```
111-build-plan-shaowear-kcol.py   生成 plan 表（行 → 值 + 依据 + 允许改动清单）
112-write-shaowear-kcol.py         --sample：改 2 格 → 回读 → 三查 → 自动回滚 → 确认复原
                                   --apply ：先补下拉清单，再分批写 K 列（30/批）
113-review-shaowear-kcol.py        独立复核：另起脚本重新拉取，三轮
```

**写入顺序**：①`00000a!F53` = 「健康体态」（补清单）→ ②`000004!K2:K137` = 书包/健康体态。
`set_range_value` 用 `value_type:'STRING'` + `string_value`（下拉值是文本）。

**小样必须挑边界型**：1 个空值行 + 1 个**错值覆盖**行（本次是序号 6023 的 8 行「儿童运动鞋」）。
