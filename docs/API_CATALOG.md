# API 索引 · 官方通道 vs 自查接口

> **本仓库的接口分两类，来源不同、稳定性不同、用法不同 —— 不要混用。**
>
> 之前混在一份清单里是错的：官方接口有文档有版本，自查接口随时会变，
> 放在一起会让人误以为「写了就能长期用」。

---

## 一、三条通道，一张表看懂

| | ① WOS 开放平台 | ② iPaaS 私域网关 | ③ 后台内部接口（自查） |
|---|---|---|---|
| **文档** | [官方-01](官方-01-WOS开放平台.md) | [官方-02](官方-02-iPaaS私域网关.md) | [自查-01](自查-01-后台内部接口.md) |
| 谁维护 | 微盟官方 | 微盟官方（私有） | 我从浏览器流量逆推 |
| 鉴权 | **OAuth**（`woscli login`） | 静态 **API Token** | 登录 Cookie + `authorization` 头 |
| 是否有文档 | ✅ 有 | ⚠️ 内部工具包 | ❌ 无 |
| 版本 / 稳定性 | ✅ 有版本，兼容有承诺 | ⚠️ 私有网关，随时可变 | ❌ 随前端发版变，字段随时改 |
| 覆盖 | **26 域 / 数百命令** | 18 个只读查询 | **38 个接口**（后台页面能做的事） |
| 写操作 | ✅ 支持 | ❌ 无 | ✅ 支持（无审计、无限流保护） |
| 限流 / 审计 | ✅ 有 | ✅ 有 | ❌ 无 |
| 该不该用在生产 | **该** | 一次性查询可以 | **不该** |

## 二、官方接口（优先用）

### ① WOS 开放平台 → [docs/官方-01-WOS开放平台.md](官方-01-WOS开放平台.md)

- OAuth 授权，凭据存系统密钥管理器，不需要明文密码
- 26 个业务域：`order` / `goods` / `marketing` / `customer` / `cdp` / `finance` / `chat-bi` …
- 命令体量：`order` 59 条、`goods` 125 条
- 支持写操作：改价、改库存、上下架、发券、订单标记
- 用法：`woscli search "<诉求>"` 先搜命令，再执行

**适用**：生产集成、定时任务、报表、对外服务。

### ② iPaaS 私域网关 → [docs/官方-02-iPaaS私域网关.md](官方-02-iPaaS私域网关.md)

- 静态 `WEIMOB_ADMIN_TOKEN`，配置比 OAuth 简单
- 18 个只读查询：商品、订单、售后、CRM、店铺概览、导购、积分/储值流水
- **无写能力**，也就没有误操作风险

**适用**：随手查几个单、几个商品；不想配 OAuth 的轻量场景。

## 三、自查接口（最后手段）

### ③ 后台内部接口 → [docs/自查-01-后台内部接口.md](自查-01-后台内部接口.md)

- 全部从 `master.weimob.com/api3/**` 的浏览器流量里逆推，**非官方、无文档**
- 38 个接口，覆盖 9 个域：商品 / 商品分组 / 素材 / 装修 / 库存 / 开屏 / 平台菜单
- 另有 **725 条权限码**（比菜单 428 条更细，可反推接口路径）

**适用**：只读巡查、WOS 没覆盖的边缘功能（如清空商品分组、清素材库）、一次性数据清理。

**不要用于**：长期跑的生产脚本、定时任务、对外服务 —— 前端一发版就可能全挂。

## 四、选型口诀

```
改数据  → WOS
查数据  → WOS（要长期）/ iPaaS（一次性）
WOS 没有 → 再看后台内部接口，且先想清楚"它坏了怎么办"
```

具体到本仓库做过的几件事：

| 做过的事 | 当时用的 | 现在建议 |
|---|---|---|
| 采集菜单地图 | ③ `queryCacheableMenus` | ③ 无替代，WOS 不提供菜单树 |
| 导出 / 删除商品 | ③ `queryGoodsListWithPage*` / `deleteGoods` | **改走 WOS**（`goods` 域有 125 条命令） |
| 清空素材库 | ③ `getMaterialList` / `deleteMaterial` | ③ 仍可用（WOS `content` 域覆盖不全） |
| 建 106 个商品分组 | ③ `addGoodsClassify` | **改走 WOS**（`goods` 域有类目/分组能力） |
| 查订单、查客户 | — | ① 或 ②，不必逆推 |
| 清空孤儿库存 | ③ `createAsyncStockTask` | WOS `goods` 域优先 |

> 也就是说：本次实操大量用了③，是因为当时只掌握了③。
> **有了官方通道后，同类需求应该优先重写成 WOS 版本。**

## 五、往这个仓库加接口时的规矩

新增任何接口记录，必须落到对应文档，不能塞进这个索引页：

| 你拿到的是 | 写进 |
|---|---|
| 微盟官方文档里的能力 / `woscli` 命令 | `官方-01-WOS开放平台.md` |
| iPaaS 网关的查询命令 | `官方-02-iPaaS私域网关.md` |
| 自己从浏览器抓到的 `api3/**` | `自查-01-后台内部接口.md` |

并且自查那一份必须标注：

1. **状态**：✅ 已验证 / ⚠️ 有条件 / ⛔ 已确认不存在
2. **实测日期**（前端发版后可能失效）
3. **踩到的坑**（参数陷阱、异步、级联行为）

> 判断标准很简单：**别人照着这份文档写代码，三个月后还能不能跑。**
> 官方那两份能，自查那份不能。
